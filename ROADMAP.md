# Roadmap

## Available

- Engine-neutral YAML/REST/UI authoring, immutable definitions and plans.
- PostgreSQL-backed queue, idempotency, quotas, cancellation and reconciliation.
- JMeter API workloads and imported/reviewed Playwright journeys in isolated Kubernetes Jobs.
- Team-scoped reports, private evidence, objective evaluation and runtime branding.
- Installation/configuration guides and portable AI-editor/CI invocation.

## Next

- Acceptance on operator-owned infrastructure; calibrate five-team workloads.
- Corporate human identity and approved secret-provider adapters.
- Native non-S3 storage adapters, private Git credentials and BrowserStack.
- Remote runner federation, hybrid wizard authoring and baseline comparison.

Provider integrations must be implemented and verified before they are advertised as supported.
